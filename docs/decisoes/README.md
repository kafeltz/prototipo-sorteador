# Registros de decisão

Cada arquivo aqui registra **uma decisão de arquitetura**: o contexto, o que
foi decidido, o que se ganha e o que se perde, e o que ficou de fora. Eles não
são atualizados quando a decisão muda: uma decisão nova substitui a antiga num
arquivo novo, e a antiga ganha um aviso no topo. Assim dá para entender, meses
depois, **por que** o projeto é como é.
